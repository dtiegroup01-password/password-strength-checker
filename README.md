# Password Strength Checker

## Project Description

Our project is a Password Strength Checker based on Cybersecurity. It checks the strength of a password using characteristics such as length, uppercase letters, lowercase letters, numbers, and special characters.

The system classifies passwords as Weak, Medium, or Strong and helps users understand how to create safer passwords.
